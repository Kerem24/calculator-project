# Calculator

A basic web-based calculator built as the final project for [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Two-input layout with instant calculation on operator click
- Clear (`C`) button to reset inputs and results
- Dark-themed responsive UI

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
